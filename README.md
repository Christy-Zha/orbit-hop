# 星轨跳跃 · Orbit Hop

一个单键操作的太空小游戏。飞船绕着星球转，点一下就沿切线弹射出去，要飞进下一颗星球的引力圈才算过关。

整个游戏只有一个 `index.html` 文件，不需要安装任何东西，用浏览器打开就能玩。手机和电脑都支持。

## 怎么玩

- **点击屏幕 / 空格**：沿切线方向弹射飞船
- **捕获**：飞进虚线引力圈，就会被那颗星球捕获
- **完美**：贴着圈边斜切进去算完美，连击越多分越高
- **别久留**：金色弧线走完后轨道开始衰减，飞船会坠向星球
- **Esc**：回到菜单

## 模式

**闯关模式**：共 10 关，最后飞进金色星门就算通关。每关最多拿 3 颗星：

1. 抵达星门
2. 完美掠入次数达标
3. 收集全部星尘

后面的关卡会出现漂移星球、小行星和会弯曲航线的黑洞。

**无尽模式**：能飞多远飞多远，越往后越难。

## 道具

| 道具 | 效果 |
|---|---|
| 盾 · 护盾 | 抵消一次失误，撞到小行星时会把它撞碎 |
| 磁 · 磁力 | 10 秒内引力圈变大，自动吸附星尘 |
| 慢 · 缓速 | 8 秒内绕转速度变慢，瞄准线变长 |
| ×2 · 双倍 | 10 秒内得分翻倍 |

## 在本地运行

直接双击 `index.html` 就能玩。最高分和关卡进度保存在浏览器本地。

## 在线发布（GitHub Pages）

1. 打开仓库的 **Settings → Pages**
2. 在 **Source** 选择 `Deploy from a branch`
3. 分支选 `main`，目录选 `/ (root)`，然后点 Save
4. 等一两分钟，就能通过 `https://<你的用户名>.github.io/<仓库名>/` 访问
